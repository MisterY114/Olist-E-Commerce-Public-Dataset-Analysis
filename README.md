# Olist 巴西电商平台数据分析

## 项目简介

本项目基于巴西电商平台 **Olist** 的真实交易数据，对 2016 年 9 月至 2018 年 10 月期间的平台运营状况进行全面、多维度的数据分析。分析覆盖了 **平台、卖家、用户** 三大核心维度，结合 SQL 和 Power BI 工具，为平台战略决策提供数据驱动的洞察。

**核心业务问题：**
- 平台营收和订单量的变化趋势如何？
- 用户满意度如何？评分的主要驱动因素是什么？
- 为什么复购率极低（仅 3.12%）？
- 哪些商品品类和卖家贡献了绝大部分 GMV？
- 如何降低对头部卖家的依赖，并拓展至渗透率较低的区域市场？

---

## 数据集说明

**数据来源**：[Olist E-Commerce Public Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)（Kaggle）  
**时间范围**：2016 年 9 月 – 2018 年 10 月  
**数据表数量**：9 张（8 张业务表 + 1 张品类翻译表）  
**总记录数**：约 155 万条

| 表名 | 说明 |
|------|------|
| `olist_customers` | 客户 ID 及地理位置信息 |
| `olist_geolocation` | 巴西邮政编码经纬度映射 |
| `olist_order_items` | 订单、产品、卖家关联信息 |
| `olist_order_payments` | 支付方式与分期金额 |
| `olist_order_reviews` | 用户评分与评论内容 |
| `olist_orders` | 订单状态与时间节点 |
| `olist_products` | 产品属性与分类 |
| `olist_sellers` | 卖家 ID 与地理位置 |
| `product_category_name_translation` | 品类名葡萄牙语 → 英语映射 |

## 核心分析结论

### 平台整体表现
- **累计 GMV**：R$15,848,899  
- **平均客单价**：R$140.69  
- **准时配送率**：92.07%  
- **订单取消率**：0.47%（非常低）  
- **平均评分**：3.99 / 5.00，4～5 星好评占比 **77%**  
- **销量 TOP5 品类**：健康美容、床浴用品、手表礼品、运动休闲、电脑配件

### 卖家生态
- 卖家总数 **3,095 个**  
- 显著的 **“二八效应”**：TOP500 卖家（占 16%）贡献了 **77.42%** 的 GMV 和 **78.73%** 的订单量  
- TOP500 卖家的平均评分（4.05）略高于平台均值（3.99），但客品数略低

### 用户行为
- **复购率仅 3.12%** — 约 97% 的用户仅下单一次  
- 用户高度集中在 **圣保罗州（SP）**（约 42%）  
- **支付偏好**：信用卡占比超 73%，其中超 75% 的用户选择 1～4 期分期付款  
- 用户流失严重：**“流失用户”** 类型占比高达 32.6%，在各类用户中排第一

## 战略建议（按优先级排序）

1. **挽留流失用户**  
   - 优化退换货流程，提升售后体验  
   - 建立 Olist 统一物流系统，增强品牌信任感  
   - 研究竞对促销活动，制定针对性反制措施

2. **调整用户运营策略**  
   - 建立会员等级体系（银卡 / 金卡 / 钻石卡）  
   - 在订单完成后 14/30/60 天推送关联品类优惠券  
   - 对首次购买用户设计“7 日内复购专属红包”

3. **扩大产品矩阵**  
   - 补全缺失分类的产品（约 610 个产品无分类）  
   - 引入高价位商品（R$200+），通过首购优惠券测试高端市场

4. **繁荣卖家生态**  
   - 头部卖家商品 + 中小卖家周边配件捆绑销售  
   - 设置“新兴宝藏品牌”专区，增加中小卖家曝光  
   - 对非 TOP500 卖家降低 1～2 个百分点佣金

5. **拓展东北部和中西部市场**  
   - 调研当地用户偏好，确定锚定商品  
   - 招募本地卖家，合作区域物流  
   - 设计区域性拉新活动（首单优惠、返券等）
